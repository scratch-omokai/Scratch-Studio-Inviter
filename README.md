# Scratch スタジオ招待

Scratch のスタジオへユーザーをまとめて招待する Chrome 拡張機能です。
拡張機能のアイコンを押すと、ブラウザの右側に**サイドパネル**が開きます。

## 機能

-   スタジオの管理者・キュレーターを招待リストに追加
-   特定ユーザーのフォロー中・フォロワーを追加
-   プロフィールのキーワードでユーザーを除外
-   ユーザー名でユーザーを除外
-   存在しないユーザーをリストから削除
-   招待リストのコピー・読み込み・クリア
-   招待間隔と人数上限の設定
-   招待間隔をランダムに最大50%長くする機能（ミリ秒単位）
-   招待の進捗・結果表示
-   実行中の停止

重複や自分自身は自動的に除外されます。

## 使い方

1.  Scratch にログインします。
2.  拡張機能のアイコンを押して、サイドパネルを開きます。
3.  招待リストを作ります。次のどちらの方法でも作れます。
    -   **元スタジオID**を入力して**「対象を取得」**を押す（現在の招待リストは置き換わります）
    -   **対象ユーザー名**を入力して、フォロー中やフォロワーを追加する
4.  必要に応じて、ユーザーの追加・除外を行います。
5.  **招待先スタジオID**を入力します。
6.  **「○人を招待」**を押して開始します。

招待間隔のデフォルトは3秒、1回の上限は100人です。

## 招待間隔のランダム化

「間隔をランダムに最大50%長くする」をオンにすると、招待のたびに、設定した間隔へ0〜50%の範囲でランダムな時間を足します。1ミリ秒単位でばらつくので、毎回違う間隔になります。たとえば間隔が10秒なら、実際の待ち時間は10.000〜15.000秒のどれかです。

待機中は、あと何秒で次の招待をするかがパネルに表示されます。デフォルトはオンです。

## プロフィール除外

指定したキーワードを、Scratch
のプロフィールの「私について」「私が取り組んでいる事」から検索し、一致するユーザーを除外します。

## 注意

-   Scratch にログインした状態で使用してください。
-   招待中は Scratch の対象タブを閉じたり移動したりしないでください。
-   サイドパネルを閉じても、Scratch のタブが開いている間は招待が続きます。
-   API
    の送信制限（429）やログイン切れ・権限不足（401/403）が発生すると処理を停止します。
-   3回連続で失敗した場合も停止します。
-   Scratch の仕様変更により動作しなくなる可能性があります。
-   大量のユーザーを処理する場合は時間がかかります。
-   Scratch のコミュニティガイドラインを守り、間隔を短くしすぎないようにしてください。

## インストール

Chrome
の拡張機能管理画面でデベロッパーモードを有効にし、**「パッケージ化されていない拡張機能を読み込む」**から
`manifest.json` のあるフォルダーを選択してください。

## 技術情報

Manifest V3 を使用しています。

主なファイル:

-   `manifest.json`：拡張機能の設定
-   `background.js`：アイコンを押したときにサイドパネルを開く処理
-   `sidepanel.html`：ユーザーインターフェース
-   `sidepanel.css`：サイドパネルの見た目
-   `sidepanel.js`：サイドパネルの処理
-   `content.js`：Scratch API との通信・招待処理

アクセス先は `scratch.mit.edu` と `api.scratch.mit.edu` です。
