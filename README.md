# Scratch スタジオ招待

Scratch のスタジオへユーザーをまとめて招待するための Chrome
拡張機能です。

元スタジオの管理者・キュレーターや、特定ユーザーのフォロー関係からユーザーを集め、招待リストを編集・絞り込みしたうえで、指定したスタジオへ順番に招待できます。

## 主な機能

-   **元スタジオからユーザーを取得**
    -   元スタジオの管理者とキュレーターを取得します。
    -   重複するユーザーと自分自身は自動的に除外します。
-   **フォロー関係からユーザーを追加**
    -   指定したユーザーがフォローしているユーザーを追加できます。
    -   指定したユーザーのフォロワーを追加できます。
    -   重複と自分自身は自動的に除外されます。
-   **プロフィールの内容による除外**
    -   Scratch
        のプロフィールに指定したワードが含まれるユーザーを除外できます。
    -   「私について」と「私が取り組んでいる事」を対象に、大文字・小文字を区別せず検索します。
-   **ユーザー名による除外**
    -   指定したユーザー名を招待リストから削除できます。
    -   招待開始時にも指定した除外ユーザーは対象から外れます。
-   **存在しないユーザーの削除**
    -   招待リスト内のユーザーが Scratch
        上に存在するか確認し、存在しないユーザーを削除できます。
-   **招待リストの編集**
    -   現在のリストを書き出してコピーできます。
    -   ユーザー名を改行・スペース・カンマ区切りで貼り付けて、一括でリストを置き換えられます。
    -   リストをすべてクリアできます。
-   **招待の進捗表示**
    -   招待済み、スキップ、存在しないユーザー、失敗の件数を表示します。
    -   実行中は進捗バーとログを表示します。
    -   実行途中で停止できます。

## 動作環境

-   Google Chrome などの Chromium 系ブラウザ
-   Manifest V3 に対応しているブラウザ
-   Scratch (`scratch.mit.edu`) にログインしていること

この拡張機能は `scratch.mit.edu` と `api.scratch.mit.edu`
へのアクセス権を使用します。

## インストール

開発版を手動でインストールする場合は、次の手順で行います。

1.  このリポジトリをダウンロードまたはクローンします。
2.  Chrome の拡張機能管理画面を開きます。
3.  **デベロッパーモード**を有効にします。
4.  **パッケージ化されていない拡張機能を読み込む**を選択します。
5.  `manifest.json` が入っているフォルダーを選択します。
6.  Scratch のページを開き、ログインした状態で拡張機能を使用します。

## 使い方

### 1. 招待対象を取得する

拡張機能のポップアップを開きます。

-   **元スタジオID**に、ユーザーを取得したいスタジオのIDを入力します。
-   **招待先スタジオID**に、ユーザーを招待するスタジオのIDを入力します。
-   必要に応じて**招待の間隔**と**1回の上限**を設定します。
-   **「1. 対象を取得」**を押します。

元スタジオの管理者とキュレーターが招待リストに追加されます。

### 2. 招待リストを調整する

取得したリストは、そのまま招待する必要はありません。

#### フォロー関係から追加

「フォロー関係から追加」でユーザー名を入力し、次のいずれかを選択します。

-   **このユーザーがフォロー中を追加**
-   **このユーザーのフォロワーを追加**

取得したユーザーは既存のリストに追加されます。

#### プロフィールで除外

「プロフィールのワードで除外」に除外したい単語を入力します。

例えば、

``` text
招待NG
invite ng
```

のように指定できます。

指定した単語がプロフィールの対象部分に含まれるユーザーは招待リストから除外されます。

#### ユーザー名で除外

特定のユーザーを除外したい場合は、「ユーザー名で除外」にユーザー名を入力します。

改行またはカンマで複数指定できます。

この除外指定は招待開始時にも適用されるため、リストに残っていても実際の招待対象には含まれません。

#### 存在しないユーザーを削除

**「存在しないユーザーを削除」**を押すと、招待リスト内のユーザーを順番に確認し、Scratch
上に存在しないユーザーを削除します。

ユーザー数が多い場合は時間がかかることがあります。

### 3. 招待を開始する

招待対象を確認したら、**「2. ○人を招待」**を押します。

開始前に確認画面が表示され、招待対象人数と概算時間を確認できます。

招待は指定した間隔を空けながら順番に実行されます。

実行中は Scratch
のタブを閉じたり、別のページへ移動したりしないでください。

## 招待の間隔と上限

### 招待の間隔

デフォルトは **3秒**です。

最小値は **0.1秒**ですが、短い間隔にすると Scratch API
の送信制限にかかる可能性があります。

送信制限が検出された場合、処理は停止します。

### 1回の上限

1回の実行で招待する人数を制限できます。

上限は **最大4000人**です。

実際の招待対象人数は、

1.  招待リスト
2.  ユーザー名による除外
3.  1回の上限

を順番に適用して決まります。

## エラー・停止時の動作

招待処理では、Scratch からの応答に応じて次のように処理します。

  状況                             動作
  -------------------------------- ----------------------------------------
  招待成功                         成功として記録
  Scratch がエラーを返した         スキップまたは失敗として記録
  ユーザーが存在しない (404)       「見つからない」として記録し、次へ進む
  送信制限 (429)                   処理を停止
  未ログイン・権限不足 (401/403)   処理を停止
  通信エラーなど                   失敗として記録
  3回連続で失敗                    処理を停止
  「停止」を押した                 現在の処理を停止

実行終了時には、招待・スキップ・見つからない・失敗の件数が表示されます。

## セキュリティとプライバシー

この拡張機能は Scratch のログイン済みブラウザ環境で動作します。

Scratch のページ上で動作するため、ブラウザが保持している Scratch
の認証状態を利用します。`content.js` では `/session/`
から現在のユーザー名を確認し、招待リクエストではブラウザの認証情報を利用します。

また、CSRF トークンを必要とする招待リクエストでは、Scratch の Cookie
に保存されている `scratchcsrftoken`
を取得してリクエストヘッダーに使用します。

**セッションIDなどの認証情報を外部サーバーへ送信する機能は実装されていません。**

ただし、この拡張機能には Scratch API および Scratch のサイト API
に対してユーザー操作を行う機能があります。信頼できないコードを混ぜた状態で使用したり、内容を確認せずに改変版をインストールしたりしないでください。

## データの保存

ポップアップで入力した次の値は `localStorage`
に保存され、次回の利用時に復元されます。

-   元スタジオID
-   招待先スタジオID
-   招待間隔
-   1回の上限
-   除外ユーザー
-   フォロー関係から追加する対象ユーザー
-   プロフィール除外ワード

招待リスト自体はページを閉じると永続保存される仕組みではなく、拡張機能の実行中の状態として管理されます。

## 技術構成

``` text
manifest.json
├── popup.html
├── popup.js
└── content.js
```

### `manifest.json`

Chrome 拡張機能の Manifest V3 設定を定義します。

Scratch のページで `content.js` を実行し、ポップアップとして
`popup.html` を表示します。

### `popup.html`

拡張機能のユーザーインターフェースを定義します。

以下の操作を提供します。

-   スタジオID入力
-   招待間隔・上限設定
-   対象取得
-   招待開始・停止
-   招待リストの表示・編集
-   ユーザーの追加・除外
-   プロフィールによる除外
-   存在確認
-   ログ・進捗表示

### `popup.js`

ポップアップの操作を処理し、Scratch タブ内の `content.js`
とメッセージをやり取りします。

入力値の保存、ユーザーリストの表示、各操作の確認、進捗表示などを担当します。

### `content.js`

Scratch のページ上で実際の API
リクエストを行い、招待リストの収集・加工・招待処理を担当します。

主な処理は次のとおりです。

-   スタジオの管理者・キュレーター取得
-   ユーザーのフォロー・フォロワー取得
-   ユーザープロフィール取得
-   ユーザーの存在確認
-   招待 API の実行
-   API のレート制限・権限エラーへの対応
-   進捗・ログ管理

## API の利用

この拡張機能は主に次の Scratch API エンドポイントを使用します。

-   `https://api.scratch.mit.edu/studios/...`
-   `https://api.scratch.mit.edu/users/...`
-   `https://scratch.mit.edu/site-api/users/curators-in/.../invite_curator/`
-   `https://scratch.mit.edu/session/`

ユーザー一覧の取得では、40件ずつページングしながら取得します。

大量のユーザーを扱う処理ではリクエスト間に待ち時間を入れ、Scratch API
の送信制限に達した場合は処理を停止します。

## 注意事項

-   Scratch の仕様変更によって動作しなくなる可能性があります。
-   Scratch API のレート制限によって処理が途中で停止する場合があります。
-   招待先スタジオへの管理権限がない場合、招待処理は実行できません。
-   招待処理中は Scratch
    の対象タブを閉じたり、移動したりしないでください。
-   大量のユーザーを処理すると、プロフィール確認や存在確認に時間がかかります。
-   自動化された大量招待が Scratch
    の利用規約・コミュニティガイドライン等に適合するかは、利用者自身で確認してください。
