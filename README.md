# Scratch スタジオ招待

Scratch のスタジオへユーザーをまとめて招待する Chrome 拡張機能です。

## 機能

-   スタジオの管理者・キュレーターを招待リストに追加
-   特定ユーザーのフォロー中・フォロワーを追加
-   プロフィールのキーワードでユーザーを除外
-   ユーザー名でユーザーを除外
-   存在しないユーザーをリストから削除
-   招待リストのコピー・読み込み・クリア
-   招待間隔と人数上限の設定
-   招待の進捗・結果表示
-   実行中の停止

重複や自分自身は自動的に除外されます。

## 使い方

1.  Scratch にログインします。
2.  拡張機能を開きます。
3.  **元スタジオID**と**招待先スタジオID**を入力します。
4.  **「1. 対象を取得」**で招待リストを作成します。
5.  必要に応じてユーザーの追加・除外を行います。
6.  **「2. ○人を招待」**を押して開始します。

招待間隔のデフォルトは3秒、1回の上限は100人です。

## プロフィール除外

指定したキーワードを、Scratch
のプロフィールの「私について」「私が取り組んでいる事」から検索し、一致するユーザーを除外します。

## 注意

-   Scratch にログインした状態で使用してください。
-   招待中は Scratch の対象タブを閉じたり移動したりしないでください。
-   API
    の送信制限（429）やログイン切れ・権限不足（401/403）が発生すると処理を停止します。
-   3回連続で失敗した場合も停止します。
-   Scratch の仕様変更により動作しなくなる可能性があります。
-   大量のユーザーを処理する場合は時間がかかります。

## インストール

Chrome
の拡張機能管理画面でデベロッパーモードを有効にし、**「パッケージ化されていない拡張機能を読み込む」**から
`manifest.json` のあるフォルダーを選択してください。

## 技術情報

Manifest V3 を使用しています。

主なファイル:

-   `manifest.json`：拡張機能の設定
-   `popup.html`：ユーザーインターフェース
-   `popup.js`：ポップアップの処理
-   `content.js`：Scratch API との通信・招待処理

アクセス先は `scratch.mit.edu` と `api.scratch.mit.edu` です。
